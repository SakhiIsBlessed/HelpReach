📋 Use Case Diagram - Detailed Breakdown

👤 DONOR ACTOR (Left Side)
Primary Function: Users who donate items to NGOs

Use Cases:
  • Register / Login: Create account or access existing account
  • View NGO Directory: Browse all registered NGOs
  • Search & Filter NGOs: Find specific NGOs by name, area, mission
  • Create Donation: Post new donation with details
  • Upload Donation Photos: Add images of items
  • Add Item Details: Specify item name, quantity, condition
  • View Donation History: See all past donations
  • Track Donation Status: Monitor if/when donation was claimed
  • View Dashboard: Personalized summary and stats
  • Manage Profile: Update personal information
  • Subscribe for Notifications: Enable alerts about donations
🏢 NGO ACTOR (Right Side)
Primary Function: Organizations that receive donations

Use Cases:
  • Register / Login: Create NGO account or login
  • View NGO Directory: Browse other NGOs (optional)
  • View Available Donations: See all donations posted
  • Search Donations: Find items matching NGO needs
  • Claim Donation: Request/claim items from donors
  • Upload NGO Documents: Submit registration/verification files
  • Manage Bank Accounts: Add/update payment information
  • View Received Donations: See all claimed items
  • Accept/Reject Donation: Confirm or decline claimed items
  • Update Profile: Manage NGO information
  • View NGO Dashboard: Organization-level statistics
  • Track Claimed Items: Monitor pickup/status
👨‍💼 ADMIN ACTOR (Top)
Primary Function: System administrators managing platform

Use Cases:
  • Manage Users: Create, edit, disable user accounts
  • Manage NGOs: Create, edit, delete NGO accounts
  • Verify NGO Documents: Approve/reject NGO verification files
  • Monitor Donations: Track all donations and claims
  • View System Reports: Analytics and statistics
  • Manage Email Settings: Configure notification templates
  • Block/Unblock Users: Suspend malicious accounts
  • System Settings & Configuration: Platform-wide settings
  • View Analytics: User engagement, donation metrics
  • Manage Disputes: Handle complaints and disputes

Donor Workflow:
Register/Login → View NGO Directory → Create Donation → Upload Photos → Submit → Track Status → View Dashboard

NGO Workflow:
Register/Login → Upload Documents → View Available Donations → Claim Item → Accept Donation → Track Pickup

Admin Workflow:
Login → Verify NGO Documents → Monitor Donations → Manage Users → View Reports → System Settings
