📋 ER Diagram Legend

PK = Primary Key (Unique identifier for each record)

FK = Foreign Key (Links to another table)

UK = Unique Key (Must be unique, like email)

||--o{ = One-to-Many relationship (One user creates many donations)

||--|| = One-to-One relationship (One donation contains one donation_item)

Relationships:

• A User creates Donations and subscribes for Push Notifications

• An NGO receives Donations, uploads Documents, and maintains Bank Accounts

• A Donation contains Items, has Photos, and can be Claimed by NGOs

• NGO Documents store verification files for NGO registration

• Email Log tracks all sent emails for auditing
