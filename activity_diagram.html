📋 Activity Diagram Walkthrough

🟢 Start: User Initiates Action
The user either logs in (if account exists) or registers a new account before accessing any donation features.
🔵 Main Donation Creation Flow
1. Browse & Select: Donor views the NGO directory and selects their target NGO
2. Create Donation: Initiates the donation posting process
3. Add Details: Enters item name, quantity, and condition
4. Upload Photos: Attaches images of the item(s)
5. Add Description: Provides detailed information and pickup instructions
🟡 Decision Point: Review & Validation
Before submission, the system checks if all required information is complete. If the donor finds an error, they can edit and correct it. Once satisfied, they submit the donation.
🟣 Notification & Waiting Phase
After posting, the system automatically notifies all matching NGOs about the available donation. The donation enters a waiting state for NGO claims (up to 30 days).
🟠 NGO Claim Process
When an NGO claims the donation, the admin receives a notification to verify the NGO's credentials, documents, and legitimacy.
🔴 Admin Verification Decision Point
If Valid: Claim is approved → Pickup instructions sent → Tracking becomes active
If Invalid: Claim is rejected → Donor notified → Donation becomes available for other NGOs again
⚫ End States
✅ Donation Complete: Successfully claimed and approved by admin
⏰ Donation Expired: No NGO claimed within 30 days - donation archived
❌ Rejected: NGO claim denied - donation remains available
