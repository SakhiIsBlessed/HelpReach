🔄 Complete Donation Process Flow
Phase 1 - Donation Creation:
Donor fills form → Frontend sends to API → API stores in DB → Confirmation shown

Phase 2 - NGO Notification:
Email service queries matching NGOs → Sends notifications → NGOs receive alerts

Phase 3 - Claim & Verification:
NGO claims donation → System verifies credentials → Either approve or reject

Phase 4 - Completion:
If approved: Send pickup instructions → Donation tracking begins
If rejected: Notify donor → Donation available for other NGOs
