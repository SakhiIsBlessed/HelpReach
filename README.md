# HelpReach

HelpReach is a web platform that connects event donors with NGOs to reduce food and resource waste.  
Donors can post surplus food or resources, and NGOs can claim and distribute them to people in need.

## Getting Started

First, start the backend server.

### Features

User and NGO registration

Donation posting system

NGO directory

Donation claiming and tracking

Email notifications

Responsive design for mobile and desktop
